## Các điểm đã kiểm lại bằng tài liệu chính thức

- **Go Lambda:** dùng OS-only runtime, đề xuất `provided.al2023`, binary Linux tên `bootstrap`, đóng gói ZIP đúng executable permissions; `aws-lambda-go` xử lý Runtime API. Tham chiếu: [Go runtime](https://docs.aws.amazon.com/lambda/latest/dg/lambda-golang.html), [đóng gói trên Linux/Windows](https://docs.aws.amazon.com/lambda/latest/dg/golang-package.html).
- **JWT cho HTTP API:** yêu cầu access-token scopes để tránh chấp nhận nhầm ID token vào API. Tham chiếu: [JWT authorizer](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-jwt-authorizer.html).
- **WebSocket:** authorizer Lambda chỉ gắn ở `$connect`; kiểm quyền cho hành động subscribe và hạn session vẫn thuộc ứng dụng. Tham chiếu: [WebSocket authorizer](https://docs.aws.amazon.com/apigateway/latest/developerguide/apigateway-websocket-api-lambda-auth.html).
- **Transaction:** cancellation có nhiều nguyên nhân, bao gồm conditional failure, conflict và capacity/validation errors. Tham chiếu: [TransactWriteItems](https://docs.aws.amazon.com/amazondynamodb/latest/APIReference/API_TransactWriteItems.html).
- **EventBridge:** HTTP 200 không đủ để kết luận mọi entry thành công; bus cấu hình sai cũng cần phát hiện bằng smoke test xuyên suốt. Tham chiếu: [PutEvents](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-putevents.html).
- **SQS:** thiết kế visibility timeout theo timeout Lambda và batching window; AWS khuyến nghị ít nhất sáu lần timeout hàm, cộng batching window, và `maxReceiveCount` ít nhất 5. Tham chiếu: [SQS event source mapping](https://docs.aws.amazon.com/lambda/latest/dg/services-sqs-configure.html).
- **Tracing:** X-Ray SDK/daemon đã vào maintenance từ 25/02/2026; tài liệu hiện hành khuyến nghị OpenTelemetry. Tham chiếu: [support timeline](https://docs.aws.amazon.com/xray/latest/devguide/xray-sdk-daemon-timeline.html). Vẫn giữ X-Ray làm backend trace.
- **SnapStart:** OS-only runtime không được hỗ trợ theo tài liệu tại thời điểm đọc. Tham chiếu: [giới hạn SnapStart](https://docs.aws.amazon.com/lambda/latest/dg/snapstart.html).
- **Terraform state:** S3 hỗ trợ `use_lockfile`; DynamoDB-based locking đã deprecated. Tham chiếu: [S3 backend](https://developer.hashicorp.com/terraform/language/backend/s3).
- **GitHub OIDC:** ràng buộc audience và subject theo repo/environment thực tế; tài liệu mới có định dạng subject chứa immutable IDs cho một số repo mới. Không chép trust policy mẫu mà chưa đối chiếu. Tham chiếu: [OIDC với AWS](https://docs.github.com/en/actions/how-tos/secure-your-work/security-harden-deployments/oidc-in-aws).
- **Hosting:** S3 private qua OAC; route thư mục của static export cần rewrite ở CloudFront. Tham chiếu: [OAC](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/private-content-restricting-access-to-s3.html), [directory indexes](https://aws.amazon.com/blogs/networking-and-content-delivery/implementing-default-directory-indexes-in-amazon-s3-backed-amazon-cloudfront-origins-using-cloudfront-functions/).
- **HTTP API:** không hỗ trợ private endpoint hay gắn WAF trực tiếp theo feature matrix. Tham chiếu: [HTTP API / REST API](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html).
- **Well-Architected:** hiện có sáu trụ cột, gồm Sustainability. Tham chiếu: [framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/the-pillars-of-the-framework.html).
